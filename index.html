The Fair Exchange Protocol in Action

How to request code, pay the dynamic invoice, and apply the patch.

Step 01 // Request

Open an Issue via Webhook

No need to grant repository read/write access or clone code locally. Just configure the MEA Webhook in your repo settings and open an issue detailing your problem.

  • Payload URL: mea-ingress.network/webhook
  • Events: Trigger only on Issues.
# You just type this on GitHub Issues:

Title: Refactor App.js to use TypeScript
Body: Please create interfaces for the User object and type the fetch calls. Ensure no memory leaks.
Step 02 // Synthesis & Invoice

MEA Audits & Generates Invoice

The MEA Cognitive Agent synthesizes the fix, runs an AST Security Audit, and calculates a price based on complexity. It then encrypts the `.patch` file and replies to your issue with the cipher and a Solana Invoice.

MEA-Bot commented 1 minute ago
AST Audit: PASSED ✅
I have synthesized the solution. Download your encrypted patch:
📥 mea_solution_issue42.enc
// SOLANA INVOICE
Amount: 0.05 SOL
Vault: MEA...VaultAddress...xyz
Memo: MEA-ISSUE-42
Waiting for on-chain settlement...
Step 03 // Settlement

Pay the Invoice On-Chain

Send the exact requested SOL amount to the Vault Address. Crucial: You must include the Issue ID in the Transaction Memo so the Solana Oracle can match the payment to your request.

* You can use Phantom Wallet, Solflare, or the Solana CLI.

# Example using Solana CLI
solana transfer \
  MEAVaultAddressXYZ1234567890 \
  0.05 \
  --with-memo "MEA-ISSUE-42" \
  --url mainnet-beta

# Signature: 5KjX... Confirmed
Step 04 // Decrypt & Apply

Instant Decryption Key

In seconds, the MEA Solana Oracle detects the payment. It replies to the GitHub thread revealing the AES-256 decryption key and IV. You decrypt the file locally and apply the patch to your code.

# 1. Decrypt the downloaded patch
openssl enc -d -aes-256-cbc \
  -in mea_solution_issue42.enc \
  -out fix.patch \
  -K <HEX_KEY_FROM_ORACLE> \
  -iv <HEX_IV_FROM_ORACLE>

# 2. Apply the patch to your repository
git apply fix.patch

# 3. Commit the perfectly typed code 🚀
