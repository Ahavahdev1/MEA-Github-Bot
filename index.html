Foco em Tipagem Estática

Aprenda a conectar a MEA ao seu repositório sem precisar clonar código, solicitar uma refatoração em TypeScript e liberar o seu patch via contrato Solana.

Passo 0 // Setup

A Ponte com a MEA (Webhook)

Para que seu repositório envie os pedidos à MEA, configure o Webhook (feito apenas 1 vez). Vá em Settings > Webhooks > Add webhook e configure exatamente assim:

  • Payload URL: A URL central do servidor.
  • Content type: application/json
  • Events: Selecione "Let me select individual events" e marque Issues.
  • Deixe Active marcado.
// 1. Insira a Payload URL exata:
https://desktop-2sltquq.tailece129.ts.net/github-webhook

// 2. Configure os parâmetros:
Content-Type: application/json
Trigger: [x] Issues
Passo 1 // Request

Como Pedir a Tipagem

A ponte está armada. Vá na aba Issues do seu repositório e clique em New Issue. O servidor central da MEA irá interceptar o pedido, analisar o código e gerar um patch limpo com IA.

# TÍTULO DA ISSUE
Refatoração: Adicionar tipagem estática e PropTypes no componente App.js

# DESCRIÇÃO (BODY)
Preciso analisar o arquivo raiz App.js e estruturar as tipagens corretas (TypeScript interfaces ou PropTypes) para garantir maior segurança de tipos. Analise a estrutura e forneça o patch limpo e refatorado.
Passo 2 // Pagamento

Pagar Fatura & Baixar Código

A MEA protege o código via protocolo Fair Exchange. O patch virá trancado. Envie o valor exato em SOL para a carteira destino informada.

⚠️ ATENÇÃO: É obrigatório incluir o código na aba "Memo" da Phantom/Solflare para o Oráculo identificar você.

Passo 3 // Decrypt

Desencriptar e Aplicar

Assim que o Oráculo detectar seu pagamento, ele publicará a chave de revelação diretamente na sua Issue do GitHub.

Use a chave revelada para descriptografar o bloco de código bloqueado e aplique o App.js perfeitamente tipado no seu projeto!

# 1. O oráculo revela sua chave na Issue:
Chave AES: clNRiyCFiZMem0VXOHy47juHjWqbkpSx6lBA7J4Ze2I=

# 2. Seu código encriptado fornecido antes:
gAAAAABqoCve_XYZ123_BLOCO_ENCRIPTADO...

# 3. Aplicando a chave, o patch é revelado:
interface UserProps {
  id: number;
  name: string;
}
// Seu código está pronto para uso! 🚀
