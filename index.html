How to Use MEA (Step by Step)

See how simple it is to integrate any repository into the ecosystem and start delegating code.

Step 0 // Configuration

Connect the Webhook

To let your repository send tasks to MEA, configure the Webhook (done only once):

  • Go to Settings > Webhooks > Add webhook in your repository.
  • Payload URL: Enter the central server URL.
  • Content type: application/json
  • Events: Select "Let me select individual events" and check Issues.
// Central Server Payload URL:

// Configuration:

Step 1 // Request

Create an Issue

Go to the Issues tab of your repository and create a new request detailing the bug, feature, or refactoring (like component typing) you need.

# ISSUE TITLE
Create secure password generator function in Python

# DESCRIPTION (BODY)
I need a pure Python function that generates complex passwords using letters, numbers, and special characters, with exception handling.

Settlement via Solana

MEA will reply in the issue with the test report, locked code (AES-256), and the dynamic SOL invoice.
