## 🔗 How to Connect Your Repository (For Testers & Users)

To have MEA write, refactor, or type code for your GitHub repositories using the central sovereign engine, you only need to configure a Webhook (no code cloning required):

**Step 1: Add the Webhook**
1. Go to your GitHub repository where you want to use MEA.
2. Navigate to `Settings` > `Webhooks` > `Add webhook`.
3. Fill in the fields:
   - **Payload URL:** `https://desktop-2sltquq.tailece129.ts.net/github-webhook` (Central Server Ingress)
   - **Content type:** Select `application/json`
   - **Trigger events:** Select "Let me select individual events" and check `Issues` (and optionally `Pull requests`).
4. Click `Add webhook`.

**Step 2: Open an Issue**
1. Go to your repository's Issues tab and click `New Issue`.
2. Describe what you need in the title and description (e.g., "Refactor App.js to add TypeScript interfaces").
3. Submit the issue. MEA will automatically intercept, synthesize, AST-audit, and encrypt the solution.

**Step 3: Fair Exchange Settlement**
1. MEA will comment on your issue with an encrypted AES-256 patch and a dynamic Solana invoice (e.g., 0.05 SOL).
2. Send the exact amount in SOL to the provided wallet with the required Memo ID (e.g., `MEA-ISSUE-X`).
3. Once confirmed on-chain, the Solana Oracle instantly publishes the decryption key in the issue thread!
